# Little Readers Level 1

Responsive sales landing page for **Little Readers Level 1**, a printable early-reading activity book for South African families.

## Checkout

All purchase buttons lead to the secure EscalePay checkout:

https://checkout.escalepay.com/5416042

## Deploy on Vercel

1. Import this GitHub repository into Vercel.
2. Keep the framework preset as **Other**.
3. Leave the build and output settings empty.
4. Select **Deploy**.

The website is static and does not require environment variables or a build command.

## Project files

- `index.html` — page content and SEO metadata
- `styles.css` — responsive layout, branding and animations
- `script.js` — navigation, reveal effects and mobile purchase bar
- `assets/` — optimised visual assets
- `vercel.json` — caching and security headers
